# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR 코드를 찍으면 휴대폰으로 보게 되는 **디지털 메뉴판**입니다.
칠판에 분필로 쓴 듯한 카페 메뉴 스타일이고, 파일 하나(`index.html`)로 만들어져 있어요.

## 주요 기능

- 커피 / 논커피 / 디저트 메뉴 15개를 이름, 가격, 한 줄 설명과 함께 보여줘요.
- 위쪽의 **전체 / 커피 / 논커피 / 디저트** 버튼을 누르면 해당 메뉴만 볼 수 있어요.
- **사장님 추천** 배지: 지정한 메뉴에 배지가 달리고 카드가 살짝 더 강조돼요.
- **오늘 품절** 표시: 품절된 메뉴는 흐려지고 '오늘 품절'이 떠요.
- 맨 아래에 영업시간과 **전화 걸기** 버튼(누르면 바로 전화 연결)이 있어요.
- 휴대폰 세로·가로 화면과 작은 화면(폭 320px)에서도 보기 좋게 맞췄어요.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 메뉴판 본체 (화면, 디자인, 메뉴 정보가 모두 들어 있어요) |
| `index_글래스모피즘_백업.html` | 예전 디자인(반투명 유리 느낌) 보관용 |
| `CLAUDE.md` | Claude와 작업할 때 지키는 규칙 |
| `자료/기획시트.png` | 가게 정보와 메뉴가 적힌 기획시트 |

## 보는 방법

`index.html` 파일을 더블클릭하면 인터넷 브라우저에서 열려요.
(손글씨 글꼴은 인터넷이 연결되어 있을 때 불러와요. 연결이 안 되면 고운 돋움이나 맑은 고딕으로 보여요.)

## 메뉴 고치는 방법

메뉴 정보는 `index.html` **맨 위쪽의 '메뉴 정보 칸'** 한 곳에 모여 있어요.
그 칸 위쪽에 한국어 주석으로 자세한 설명이 있으니, 처음이라면 먼저 읽어보세요.

메뉴 한 개는 아래처럼 한 줄이에요.

```js
{ 이름: "아인슈페너", 가격: "5,800원", 설명: "단맛을 줄인 수제 크림", 추천: 1, 품절: 0 },
```

- **가격 바꾸기**: `가격: " "` 안의 글자만 고쳐요.
- **메뉴 추가하기**: 메뉴 줄 하나를 통째로 복사해서 아래에 붙여넣고, 글자만 바꿔요.
- **메뉴 지우기**: 그 줄을 쉼표까지 통째로 지워요.
- **추천 켜고 끄기**: `추천: 0`은 꺼짐, `추천: 1`은 켜짐이에요.
- **품절 켜고 끄기**: `품절: 0`은 판매 중, `품절: 1`은 품절이에요.

고친 뒤에는 저장(Ctrl+S)하고, 브라우저에서 새로고침(F5)하면 바로 바뀌어요.

## 가게 정보 고치는 방법

- **가게 이름, 한 줄 소개**: `index.html`의 `<header>` 부분 글자를 고쳐요.
- **영업시간, 전화번호**: `<footer>` 부분을 고쳐요. 전화번호는 `href="tel:..."`(숫자만)과 버튼에 보이는 글자, 두 곳을 같이 고쳐야 해요.
- **색상**: 파일 위쪽 CSS의 `:root` 안 `#번호`를 고쳐요.

## 사용한 기술

HTML, CSS, JavaScript만 사용했어요. 별도의 설치나 복잡한 도구는 필요 없어요.
